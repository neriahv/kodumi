# Kodumi brand identity

**Name:** Kodumi. **Wordmark:** `kodumi`. **Pronunciation:** koh-DOO-mee.

**Primary tagline:** Your AI coding crew.

**Supporting line:** Small crew. Thoughtful code.

## Direction

A cozy coding workshop for curious developers. Friendly characters explain the engineering process, while precise status labels and visible evidence establish credibility. The visual concept is included in `brand-concept.png`; it is AI-generated concept artwork, not an application screenshot or a production vector logo.

| Token | Color | Use |
| --- | --- | --- |
| Ink | #20212B | Dark surfaces and primary text |
| Paper | #F7F5F0 | Light background |
| Lilac | #B9A1F5 | Main accent and mascot |
| Coral | #F38679 | Warm illustration accent |
| Mint | #9ED9C5 | Supporting accent and successful checks |

Light-mode controls use darker companion colors for contrast. Diffs retain conventional red/green meanings. Agent identity is communicated through labels and props as well as color.

## Mascot and crew

The main character is a small lilac code creature with curly-bracket arms. Four SVG variants share the same silhouette:

- **Scout:** teal investigator with a magnifying glass.
- **Atlas:** amber architect with a blueprint.
- **Forge:** coral builder with a code tile.
- **Pixel:** mint tester with a check tile.

The wordmark uses rounded, heavy lettering with a coral square accent. System font stacks are intentionally used for offline operation; self-hosted licensed font files can be introduced through `public/assets/fonts.css` later.

## Voice

Friendly, specific, and honest. Prefer “Two tests still fail” over “Your code is now perfect.” Report observable actions instead of inventing progress or exposing private model reasoning. Do not label deterministic labs as AI-generated fixes, or skipped tests as passing.

The working name has not received trademark, domain, or social-handle clearance. A similar AI-platform name, Kodosumi, exists; review naming before a commercial launch.
